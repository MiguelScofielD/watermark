# 🖼️ Watermark App

A simple and elegant desktop application built with Python and Tkinter that allows users to upload images and automatically add a custom watermark.

---

## 🚀 Preview

### Features

✅ Upload images
✅ Add PNG watermark with transparency
✅ Automatic watermark resizing
✅ Watermark positioning (bottom-right corner)
✅ Save final image automatically
✅ Open processed image after generation
✅ Simple graphical interface with Tkinter

---

| Technology   | Purpose                   |
| ------------ | ------------------------- |
| Python       | Main programming language |
| Tkinter      | Graphical user interface  |

# 🛠️ How It Works

1. The user uploads an image.
2. The application loads the image using Pillow.
3. A PNG watermark with transparency is loaded.
4. The watermark is automatically resized proportionally.
5. The watermark is placed in the bottom-right corner.
6. The final image is saved.
7. The processed image is automatically opened.

# ▶️ Installation

## Clone the repository

```bash
git clone https://github.com/MiguelScofielD/watermark.git
```

## Access the folder

```bash
cd watermark
```

## Create virtual environment

```bash
python -m venv venv
```

## Activate virtual environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

## Install dependencies

```bash
pip install pillow
```

---

# ▶️ Run the Project

```bash
python main.py
```
